# Feature: Icon Preview Context Menu

## Use case

As a user, I want to explore my options on the icon preview with a context menu.
As a user, I want to paste with the context menu to quickly update the icon.
As a user, I want to copy the icon to use it for another bookmark.
As a user, I want to delete the icon via the context menu.
