# Feature: Paste Icon in Select Icon Overlay. 

## Description

As a user, I want to be able to paste an icon from the clipboard into the select icon overlay.

A user can paste a data URI icon, or a SVG icon or a URL to an icon.
The icon will be added to the internal icon cache and displayed as selected in the select icon overlay.
