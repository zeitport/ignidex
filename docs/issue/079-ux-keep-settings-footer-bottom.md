# UX: Settings Footer shall Stay at the Bottom. 

## Description

As a user, it annoys me when the settings footer moves up and down when 
- opening different settings panels or 
- scrolling the settings overlay.

## Plan

- Review this issue and ask questions to improve the plan and clarify unclear requirements.
- Document answers in section [Clarifications]
- Implement based on description and clarifications
- Keep the settings footer at the bottom of the settings overlay, even when scrolling or opening different settings panels.
- Let the settings navigation allow to scroll independently of the settings content.
