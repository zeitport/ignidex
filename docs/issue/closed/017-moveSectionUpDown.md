# Feature: Move a section up/down

## Use case

As a user I want to move a section up or down to achieve better organization.

## Implementation

- Add the "Move up" action to a section context menu
- Add the "Move down" action to a section context menu
- Save changes to the database
- Use icons mdiArrowUpThin, mdiArrowDownThin

## Validation

- Run `npm run lint` to check for lint errors
- Run `npm run tsc` to run the TypeScript compiler
