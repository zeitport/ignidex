# Icon Preview Click: Open Image Asset Viewer

## Description

As a user, when I click on an icon preview, I want to open the image asset viewer to select an existing image for my bookmark.

WHEN a user clicks on an icon preview (e.g: Edit Bookmark)
THEN show the image asset viewer as a sub overlay.

WHEN a user clicks on an image in the "image asset viewer"
THEN use this image and preview it in the icon preview.
