# Feature: Move bookmark card up/down

## Use case

As a user I want to move a bookmark card up or down in the list (group) to achieve better organization.

## Implementation

- Add "Move up" action to bookmark context menu
- Add "Move down" action to bookmark context menu
- Save changes to database
- Use icons mdiArrowUpThin, mdiArrowDownThin

## Validation

- Run `npm run lint` to check for lint errors
- Run `npm run tsc` to run the TypeScript compiler
