# Contributing to Ignidex

Thank you so much for using Ignidex — or even just trying it out!

## Feedback is Welcome

Your feedback helps make Ignidex better for everyone.
Whether it's a bug you stumbled upon, an idea you'd love to see, or just sharing how things went when you gave it a spin — all of it is genuinely appreciated.

Here are some great ways to contribute right now:

- **Testing**, try out Ignidex and let me know how it goes.
- **Bug reports**, found something that doesn't work quite right?
- **Ideas and suggestions**, how something could be improved? Let me know.

Feel free to open an issue on the repository to start a conversation.

## Code Contributions

Ignidex is currently in a **stabilization phase**. During this time, code contributions (pull requests) 
will not be accepted unless they have been discussed and agreed upon beforehand.

If you'd like to contribute code, please open an issue first to talk about what you have in mind.

Thank you for understanding! Enjoy your caffè.
